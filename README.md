# Расписание

Минималистичное веб-приложение расписания для университета (весенний семестр 2025).
Статический сайт без сборки: откройте `index.html` или опубликуйте папку на любом статическом хостинге.

## Возможности

- Выбор направления (Менеджмент, Прикладная математика и информатика, Юриспруденция, Биология, Фармация + вторая группа направлений).
- Навигация по дням: вкладки дней недели, стрелки «предыдущий/следующий учебный день», кнопка «Сегодня».
- Отображение времени, дисциплины, преподавателя и аудитории; подсветка текущей пары; склейка смежных одинаковых пар.
- Тёмная/светлая тема: внутри Telegram — тема клиента, в браузере — светлая.

## Telegram

Приложение использует [Telegram Web Apps JS API](https://core.telegram.org/bots/webapps):

- тема и цвета интерфейса берутся из Telegram (`themeParams`, `colorScheme`);
- выбранное направление сохраняется в `CloudStorage` (в браузере — `localStorage`);
- `HapticFeedback` на переключения, `BackButton` для возврата к сегодняшнему дню;
- `MainButton` «Отправить расписание дня» пересылает день через `sendData` боту;
- имя пользователя показывается в шапке (`initDataUnsafe.user`).

Загрузка `telegram-web-app.js` — динамическая с таймаутом: вне Telegram приложение работает автономно.

`bot.example.js` — пример бота (Bot API, Node.js 18+, без зависимостей):
кнопка меню открывает мини-апп, `/start` присылает расписание сегодняшнего дня,
`sendData` из мини-аппа принимается через вебхук.

## Данные

`lessons.json` — расписание, распарсенное из исходного `Расписание.xlsx`
(95 учебных дней, 10.02.2025 — 31.05.2025, 8 направлений, 2305 занятий).
Компактный формат со справочниками: `days` (даты), `groups` (направления),
`slots` (пары времени), `subjects` (дисциплины с преподавателями), `rooms` (аудитории);
каждая запись в `lessons` — `[индекс дня, индекс группы, индекс слота, индекс предмета, индекс аудитории (−1, если нет)]`.

## Структура

- `index.html` — разметка
- `style.css` — стили (CSS-переменные темы)
- `app.js` — логика + интеграция с Telegram
- `lessons.json` — данные расписания
- `bot.example.js` — пример Telegram-бота
